# Koma GIF

画像を並べ、表示時間・出力比率・クロスフェードを調整してGIFスライドを書き出すブラウザアプリです。画像は外部サーバーへ送信せず、端末内で処理します。

**Web版:** https://sakiikavr.github.io/koma-gif/

## 起動

```bash
npm install
npm run dev
```

表示されたローカルURLをブラウザで開いてください。「このフォルダの5枚を読み込む」から同梱サンプルをすぐ試せます。

## 機能

- JPG・PNG・WebPの複数選択／ドラッグ＆ドロップ
- ドラッグまたは矢印による並べ替え
- 画像ごとの表示時間
- 正方形・横長・縦長・カスタム出力
- 全体表示／画面いっぱい、余白色の指定
- クロスフェード／即時切り替え
- 無限ループ／1回再生
- ブラウザ内プレビューとGIFダウンロード

## 確認

```bash
npm test
npm run build
```

GIFエンコードにはMITライセンスの [`gifenc`](https://github.com/mattdesl/gifenc) を使用しています。
